# Links

A simple, free "link in bio" page for Instagram — no Linktree needed.

## Edit your links
Open `index.html` and change the `PROFILE` block near the bottom (name, bio, links).
Put a square photo named `avatar.png` next to `index.html` for your profile picture.

## Publish for free (GitHub Pages)
1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)` → Save
3. After a minute your page is live at `https://<your-username>.github.io/<repo-name>/`
4. Paste that URL into your Instagram bio.
